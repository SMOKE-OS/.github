About SMOKE OS

SMOKE OS is an independent Linux distribution project built on Arch Linux and designed around the Hyprland Wayland compositor.

Our vision is to create a clean, lightweight, visually cohesive desktop experience that prioritizes simplicity, performance, customization, and user freedom.

We believe great software doesn't need unnecessary complexity.

Our Philosophy

- Minimalism — Every component should serve a purpose.
- Performance — Keep the system lean and responsive.
- Customization — Make the desktop yours.
- Transparency — Develop openly and document our decisions.
- Reliability — Test changes before including them in releases.
- Freedom — Built around open-source software and user control.

Technology Stack

Component| Technology
Base system| Arch Linux
Desktop compositor| Hyprland
Status bar| Waybar
Package manager| Pacman
Init system| systemd
ISO builder| Archiso
Bootloader target| systemd-boot
Boot splash target| Plymouth

Planned components may change during development and are not necessarily implemented yet.

Project Status

🚧 Early development — not yet a stable release.

Current priorities:

- Build a reproducible bootable ISO.
- Integrate and configure the Hyprland desktop.
- Create custom branding and boot artwork.
- Develop installation and recovery workflows.
- Establish automated testing and release procedures.

Development builds are experimental. Test them in a virtual machine before using them on physical hardware.

Contributing

- Suggest features with a clear explanation of their value.
